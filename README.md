# Codex Desktop

Небольшое настольное приложение для Windows, которое запускает установленный Codex CLI в выбранной папке проекта. Окно и список чатов сгруппированы по проектам.

## Запуск

Нужен .NET 10 SDK и установленный Codex CLI с действующим входом. Дважды нажмите `Run-CodexGUI.cmd`. При первом запуске .NET соберёт приложение; далее его можно запускать тем же файлом.

## Релизы и обновления

Релизная версия состоит из трёх числовых частей: `XXX.YYY.ZZZ`. Начальная версия — `0.0.001`; соответствующий тег Git — `v0.0.001`. Отправка тега такого вида запускает `.github/workflows/release.yml`: workflow публикует автономный `CodexGUI.exe` с его SHA-256, а также self-contained архив `CodexGUI-win-x64.zip` с исходным XAML для разработки интерфейса и его собственным SHA-256. Для следующего выпуска увеличьте версию в `<Version>` файла `CodexGUI.csproj`, создайте соответствующий тег с префиксом `v` и отправьте его.

Для первой установки скачайте `CodexGUI.exe` и разместите его в доступной для записи папке пользователя, например `%LOCALAPPDATA%\Programs\CodexGUI`. Автономный EXE содержит разметку интерфейса и сценарий обновления. ZIP дополнительно содержит отдельный XAML-файл для редактирования интерфейса на лету. Приложение проверяет GitHub Releases при запуске; новые версии также можно проверить через меню значка в системном трее. После согласия архив загружается, сверяется по SHA-256, файлы обновляются в текущей папке и приложение перезапускается. Не размещайте приложение в `Program Files`: автоматическому обновлению нужна запись в папку установки.

Выберите проект слева. Кнопка `＋` над списком позволяет создать папку нового проекта или добавить существующую. Новые чаты создаются внутри выбранного проекта и продолжаются в той же папке. Щелкните правой кнопкой по чату, чтобы архивировать его или удалить. Кнопка `Архив` над списком чатов открывает архив; оттуда чат можно восстановить. Удаление также удаляет сохраненный сеанс из Codex CLI и требует подтверждения. Список проектов и чатов сохраняется в `%LOCALAPPDATA%\CodexGUI\state.json`; историю диалогов хранит сам Codex CLI.

Иконка Codex остаётся в системном трее, пока приложение запущено. Сворачивание окна прячет его в трей; щелчок по иконке возвращает окно. В контекстном меню доступны открытие, новый чат и выход. Закрытие окна завершает приложение.

В композере можно выбрать модель из каталога установленного Codex CLI и поддерживаемый ею уровень усилий; оба значения всегда заданы и сохраняются между запусками. Если сохраненного выбора еще нет, используются GPT-6-Luna и высокие усилия. Кнопка `Скриншот` позволяет выделить область экрана, сохранить её в PNG и добавить путь к изображению в запрос Codex. Здесь же отображаются оставшиеся лимиты Codex на 5-часовое и недельное окна со временем сброса; они обновляются при запуске, после запроса и каждые пять минут через `account/rateLimits/read` app-server. Режим по умолчанию — `Попросить подтверждение`: Codex может менять файлы проекта, а для действий за его пределами использует запрос подтверждения (`on-request`). Режим `Полный доступ` включает опасный флаг CLI без песочницы и подтверждений; приложение отдельно спрашивает согласие перед его включением. Настроенный в Codex профиль сохраняется.

## Изменения интерфейса на лету

Визуальная структура находится в `Views/WorkspaceView.xaml`. Пока приложение открыто, сохранение этого файла автоматически перечитывает разметку и обновляет окно без перезапуска. Если разметка временно некорректна, приложение оставляет предыдущую версию экрана и показывает ошибку. Поведение приложения и интеграция с CLI находятся в `MainWindow.xaml.cs`; изменения C# требуют нового запуска.

Приложение не включает отдельную копию модели и не хранит токены. Запросы передаются установленному `codex` CLI. Иконка приложения находится в `Assets/codex-assistant.png` и `Assets/codex-assistant.ico`.
